Fafnyir Tools for EllesmereUI v1.1.7 — SharedMedia Arrows and Role Icons

v1.1.7 changes

- Added a Nameplate Target Arrow selector under FafnyirTools Unit Frames.
- Uses SharedMedia arrow backgrounds, including FafnyirMedia's - Arrow Glow.
- Excludes role and combat images from the target-arrow selector.
- Added an optional FafnyirMedia Party / Raid Role Icons toggle using the
  registered Tank, Healer and DPS artwork.
- Preserves EllesmereUI visibility, size, position and arrow color settings.
- Defaults to native artwork, restores it when disabled and preserves saved settings.
- Includes the new preferences in global settings transfer and diagnostics.
- User confirmed arrows and Party/Raid role icons work in game.
  Detailed combat/reload scenarios remain separate manual checks.

v1.1.6 changes

- Added Copy Diagnostics to the About page.
- Added a copyable report with addon, client, interface, EllesmereUI,
  FafnyirMedia, options-registration and enabled-feature information.
- Excluded character names, realm, account information and raw SavedVariables
  from the report.
- Added a chat fallback if EllesmereUI's native copy popup is unavailable.

v1.1.5 changes

- Removed Blizzard Bar Art and Unit Frame Sources; EllesmereUI now provides both.
- Removed Party and Raid support from FafnyirTools name display modes because
  EllesmereUI now provides those controls; main unit frames remain supported.
- Left existing legacy saved keys untouched during ordinary upgrades.
- Added FafnyirMedia as a required dependency alongside EllesmereUI.
- Removed FafnyirTools XP Bar border controls; EllesmereUI now owns this setting.
- Removed FafnyirTools XP Bar text overrides; EllesmereUI now owns the layout.
- Fixed XP layers: current XP is on top, Rested XP is second, and Quest XP is behind both.
- Limited Flyout Fix to Retail; it is hidden and inactive on WoW Forever.
- Reworked Retail Flyout Fix to preserve Blizzard's native button geometry and
  background while fitting only EllesmereUI's selected decorative border.
- Prevented hidden pooled flyout buttons from reappearing in shorter menus.
- Removed unnecessary ACTIONBAR_SLOT_CHANGED and UPDATE_BINDINGS refreshes from
  Right-Click Self Cast, preventing repeated 180-button scans during action and
  modifier-state churn while retaining dynamic paging through secure attributes.
- Added a persistent, default-off Icon History border toggle under QoL with a
  dropdown containing EllesmereUI's complete live border-style list.
- Fixed enabled Icon History borders requiring an off/on toggle after reload.
- Hidden the Forever Volumetric Fog control because Blizzard now overrides
  addon changes to that setting.
- Stopped reapplying the unsupported volumeFog console setting.
- Retained the legacy saved preference for upgrade and export compatibility.

v1.1.4 features

Added
- WoW Forever interface 16001 support and runtime detection.
- Current Pet Journal owned-ID enumeration with the legacy fallback retained.

Fixed
- Reload confirmation buttons now use EllesmereUI's secure Forever reload path,
  avoiding the protected-action failure from direct ReloadUI callbacks.
- Blizzard Bar Art now restores itself after action-bar state/layout changes and
  reacquires Blizzard artwork if the live regions are replaced.
- Added an Art Scale slider (1.00–1.10, default 1.06). This local calibration is
  excluded from Global Settings exports so different machines can use different values.

Changed
- Resting max-level detection now follows client APIs instead of a Retail level constant.
- Unit Frame source writes, settings import/restore and Full Reset are guarded
  while EllesmereUI reports the Forever beta SavedVariables defect.

Persistence
- Export remains available during the beta persistence defect.

Scope
This cleanup build is offline-validated for the supported Retail and WoW
Forever interfaces. Its UI behavior still requires in-game confirmation.
