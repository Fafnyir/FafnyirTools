Fafnyir Tools for EllesmereUI v1.1.5 — Cleanup

v1.1.5 changes

- Hidden the Forever Volumetric Fog control because Blizzard now overrides
  addon changes to that setting.
- Stopped reapplying the unsupported volumeFog console setting.
- Retained the legacy saved preference for upgrade and export compatibility.

v1.1.4 features

Added
- WoW Forever interface 16001 support and runtime detection.
- Current Pet Journal owned-ID enumeration with the legacy fallback retained.

Fixed
- Reload confirmation buttons now use EllesmereUI's secure Forever reload path,
  avoiding the protected-action failure from direct ReloadUI callbacks.
- Blizzard Bar Art now restores itself after action-bar state/layout changes and
  reacquires Blizzard artwork if the live regions are replaced.
- Added an Art Scale slider (1.00–1.10, default 1.06). This local calibration is
  excluded from Global Settings exports so different machines can use different values.

Changed
- Resting max-level detection now follows client APIs instead of a Retail level constant.
- Unit Frame source writes, settings import/restore and Full Reset are guarded
  while EllesmereUI reports the Forever beta SavedVariables defect.

Persistence
- Export remains available during the beta persistence defect.

Scope
This cleanup build is offline-validated for the supported Retail and WoW
Forever interfaces. Its UI behavior still requires in-game confirmation.
