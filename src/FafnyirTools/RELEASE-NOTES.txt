Fafnyir Tools for EllesmereUI v1.1.18

v1.1.18 changes

- Completes reviewed Simplified Chinese (zhCN) and Traditional Chinese (zhTW)
  coverage for all 187 current interface strings.
- Integrates Yilang's reviewed Leveling Forecast translations.
- Integrates Yilang's reviewed BigWigs Border, Content Spacing, and click-only
  Center Reticle wording.
- Preserves all v1.1.17 feature behavior, defaults, saved settings, and
  EllesmereUI ownership boundaries.

Special thanks

- Thank you to Yilang for reviewing and refining the Chinese localization.

v1.1.17 changes

- Adds a default-off QoL toggle and live dropdown of all current EllesmereUI borders for BigWigs timer bars, attached spell icons, and normal message icons; Pixels remains the default.
- Adds a saved 0–10 pixel Content Spacing slider that leaves timer-bar spell icons and indicators fixed; zero preserves BigWigs' native layout.
- The same Content Spacing slider separates normal message icons from their text and restores both displays at zero or when disabled.
- Does not modify BigWigs profiles or its native nameplate icon settings.
- BigWigs Border and Border Style changes use a Reload Now/Later confirmation
  so their saved values apply cleanly without interrupting EllesmereUI controls.
- Adds a default-off Reticle Only While Clicking option for EllesmereUI's Center
  Reticle. The center dot appears while either mouse button is held while its
  native color, opacity, size, and saved preference remain under EllesmereUI.
- Includes first-pass Simplified and Traditional Chinese translations for the
  new v1.1.17 controls pending Yilang's review.

Testing requested

- User-confirmed the reload-applied BigWigs controls and click-only Center
  Reticle in game. Broader border-style, combat-safety, and Chinese layout
  coverage remains welcome.

v1.1.16 changes

- Extended completed-quest projections across multiple Midnight levels through
  level 90.
- Uses the live current-level XP requirement as a guard before applying the
  bundled Midnight 12.1 future-level requirements.
- Falls back to the conservative one-level overflow display if Blizzard changes
  the live XP curve.
- Shows projected percentage progress at the resulting level or Maximum Level
  when the completed quests would reach level 90.
- Placed the two forecast guidance messages on separate full-width rows to
  prevent the overlap visible in v1.1.15.
- Remains read-only and does not alter EllesmereUI's XP bar, settings or events.

v1.1.15 changes

- Added a read-only Leveling Forecast under QoL.
- Shows completed quest XP, the effective applicable quest-XP bonus, and
  projected progress after turn-ins.
- Leaves EllesmereUI's XP bar, settings, events and artwork untouched.
- Exact within the current level; next-level overflow is clearly marked as an
  estimate boundary instead of using a hard-coded future XP table.
- Reopen the QoL page to refresh the forecast.

v1.1.14 changes

v1.1.7 changes

- Uses SharedMedia arrow backgrounds, including FafnyirMedia's - Arrow Glow.

v1.1.6 changes

- Added Copy Diagnostics to the About page.
- Added a copyable report with addon, client, interface, EllesmereUI,
  FafnyirMedia, options-registration and enabled-feature information.
- Excluded character names, realm, account information and raw SavedVariables
  from the report.
- Added a chat fallback if EllesmereUI's native copy popup is unavailable.

v1.1.5 changes

- Removed Blizzard Bar Art and Unit Frame Sources; EllesmereUI now provides both.
- Removed Party and Raid support from FafnyirTools name display modes because
  EllesmereUI now provides those controls; main unit frames remain supported.
- Left existing legacy saved keys untouched during ordinary upgrades.
- Added FafnyirMedia as a required dependency alongside EllesmereUI.
- Removed FafnyirTools XP Bar border controls; EllesmereUI now owns this setting.
- Removed FafnyirTools XP Bar text overrides; EllesmereUI now owns the layout.
- Fixed XP layers: current XP is on top, Rested XP is second, and Quest XP is behind both.
- Limited Flyout Fix to Retail; it is hidden and inactive on WoW Forever.
- Reworked Retail Flyout Fix to preserve Blizzard's native button geometry and
  background while fitting only EllesmereUI's selected decorative border.
- Prevented hidden pooled flyout buttons from reappearing in shorter menus.
- Removed unnecessary ACTIONBAR_SLOT_CHANGED and UPDATE_BINDINGS refreshes from
  Right-Click Self Cast, preventing repeated 180-button scans during action and
  modifier-state churn while retaining dynamic paging through secure attributes.
- Added a persistent, default-off Icon History border toggle under QoL with a
  dropdown containing EllesmereUI's complete live border-style list.
- Fixed enabled Icon History borders requiring an off/on toggle after reload.
- Hidden the Forever Volumetric Fog control because Blizzard now overrides
  addon changes to that setting.
- Stopped reapplying the unsupported volumeFog console setting.
- Retained the legacy saved preference for upgrade and export compatibility.

v1.1.4 features

Added
- WoW Forever interface 16001 support and runtime detection.
- Current Pet Journal owned-ID enumeration with the legacy fallback retained.

Fixed
- Reload confirmation buttons now use EllesmereUI's secure Forever reload path,
  avoiding the protected-action failure from direct ReloadUI callbacks.
- Blizzard Bar Art now restores itself after action-bar state/layout changes and
  reacquires Blizzard artwork if the live regions are replaced.
- Added an Art Scale slider (1.00–1.10, default 1.06). This local calibration is
  excluded from Global Settings exports so different machines can use different values.

Changed
- Resting max-level detection now follows client APIs instead of a Retail level constant.
- Unit Frame source writes, settings import/restore and Full Reset are guarded
  while EllesmereUI reports the Forever beta SavedVariables defect.

Persistence
- Export remains available during the beta persistence defect.
