Fafnyir Tools v2.0.0

v2.0.0 changes

- Makes EllesmereUI and FafnyirMedia optional dependencies.
- Adds a native movable `/faftools` settings window when EllesmereUI is absent.
- Provides the portable Fafnyir Tools feature set in standalone mode while
  preserving all existing integrations when EllesmereUI is installed.
- Keeps EllesmereUI-only features hidden in standalone mode and preserves their
  saved settings for later use.
- Adapts Right-Click Self Cast to Blizzard native action bars.
- Skins the standalone window with the Fafnyir palette, compact sizing and
  pixel borders; uses Roboto SemiBold for headings/tabs/buttons and Roboto
  Regular for body copy, with safe fallbacks.
- Restores the Fafnyir Tools title in the standalone header.
- Keeps slider value labels centered beside their controls instead of bleeding
  below a row or into the following section.
- Includes first-pass Chinese strings pending Yilang's review.
- Integrates the author's former HideTargetRepColor behavior through the
  existing Target/Focus status-texture handler.
- Adds a default-off movable FPS/world-latency display with font-size and
  position controls plus the legacy `/fpsdisplay` shortcut.
- Adds a default-off Nicer Damage font toggle with Reload Now/Later handling.
- Adds a default-off standalone option to hide Blizzard's default unit-tooltip
  health bar without changing tooltip visibility.
- Adds default-off Mouseover Action Bars controls under Action Bars for
  Blizzard's primary, multi, Pet and Stance bars with configurable opacity.
- Adds individual bar selections and requests Reload Now/Later when Mouseover
  Action Bars is first enabled.
- Includes separate Micro Menu and Bag Bar mouseover selections.
- Adds a draggable standalone minimap button for opening Fafnyir Tools; its
  device-specific position is excluded from global exports.
- Uses the supplied Fafnyir dragon logo for the standalone minimap button.
- Adds bounded bottom-right resizing to the standalone settings window, saves
  its dimensions per installation, and includes an About-page size reset.
- Restores the branded addon-list icon from the logo bundled with FafnyirTools.
- Tightens and vertically centers standalone text-only rows while preserving
  the full spacing used by interactive controls.
- Adds standalone XP & Progression controls for Blizzard's native Experience
  bar: current/rested gradients, direction, colors and completed Quest XP.
- Masks custom XP textures with the active client's native track shape so the
  Retail and Forever end caps keep their intended bounds.
- Uses the native fill silhouette for that mask so gradient colors remain at
  their configured brightness and opacity.
- Draws rested XP as an explicit forward segment between current XP and Quest
  XP, making the intended current/rested/Quest layer order unambiguous.
- Reapplies custom XP textures in Blizzard's own update cycle to prevent a
  one-frame native/custom flicker.
- Keeps the native XP feature entirely inactive when EllesmereUI is installed.

Testing requested

- Test native settings, popups, scrolling and every portable feature without
  EllesmereUI on Retail and Forever.
- Re-enable EllesmereUI and confirm the complete integration surface returns.
- Verify FPS display dragging/persistence and Nicer Damage floating combat text
  in standalone Retail and Forever.
- Verify default unit tooltips hide and restore their health bar live without
  taint on Retail and Forever.
- Verify mouseover reveal, leave delay, partial opacity and disable restoration
  for every Blizzard action-bar group in Retail and Forever.
- Verify the minimap button click, tooltip, drag persistence and placement at
  different UI scales on Retail and Forever.
