Scope
This restores previously implemented features; it does not add the discarded
Masque, DataBroker or Warband Mail selector experiments. Focus aura styling
and full mail/auction/warband/guild inventory scanners remain unimplemented.

Installation
Replace FafnyirTools under Interface/AddOns, then reload. Keep SavedVariables.
Permanent Companion Pet is off by default unless previously enabled; configure
it under QoL. All five source controls retain their prior settings.
No EllesmereUI files are modified. Offline regression checks pass; verify the
restored pet, seven-page layout and mixed frame setup in game before publishing.
