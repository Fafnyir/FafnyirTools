The safest approach is to keep WordPress and rebuild only the homepage first. Your blog, vinyl collection, and existing UI page can remain online throughout.

## 1. Back up the website

Before changing anything:

- Create a full hosting backup.
- Update WordPress, Inspiro, and plugins.
- If your host offers staging, create a staging copy and work there.

Avoid editing Inspiro’s theme files directly; updates would overwrite those changes. Use the Customizer, page blocks, or a child theme for custom code. [WordPress recommends a child theme for theme-level customization](https://developer.wordpress.org/themes/advanced-topics/child-themes/).

## 2. Create a new homepage

In WordPress:

1. Open **Pages → Add New**.
2. Name it **Home New**.
3. In the page settings, select a full-width or no-sidebar template if Inspiro provides one.
4. Build the page with WordPress blocks.
5. Keep it unpublished or save it as a draft until finished.

Use this structure:

### Opening section

- Add a **Cover block**.
- Upload your best full-screen FafnyirUI screenshot.
- Apply a dark overlay.
- Add:

> **FafnyirUI**  
> A clean, immersive World of Warcraft interface.

- Add three Button blocks:
  - Download FafnyirMedia
  - Download Fafnyir Tools
  - Import UI Profile

Point them to the appropriate CurseForge and Wago pages.

### Features

Add a three-column section:

  Keeps important combat information visible without unnecessary clutter.

  Custom fonts, textures and shared media through FafnyirMedia.

- **EllesmereUI integration**  
  Additional tools and a ready-to-import profile for a consistent layout.

### Requirements

Use a simple list or cards:

1. EllesmereUI — Download
2. FafnyirUI Profile — Import from Wago
3. FafnyirMedia — Download from CurseForge
4. Fafnyir Tools for EllesmereUI — Download from CurseForge

Clearly label every button; don’t use “Download” four times without identifying the item.

### Installation

Add these instructions, adjusting them to match your actual process:

4. Open EllesmereUI.
5. Copy the FafnyirUI profile string from Wago.
6. Import the profile and apply it.
7. Reload the interface with `/reload`.

Include separate Retail, Classic, or Cataclysm instructions if compatibility differs.

### Gallery and version information

Add:

- Three to six screenshots showing combat, party/raid frames and configuration.
- Current release number.

- Last-updated date.

## 3. Set it as the homepage

When the new page is ready:

1. Open **Settings → Reading**.
2. Select **A static page**.
3. Set **Homepage** to **Home New**.
4. Leave **Posts page** set to Blog.
5. Save changes.

These are the official [WordPress static-homepage instructions](https://wordpress.org/documentation/article/create-a-static-front-page/).
