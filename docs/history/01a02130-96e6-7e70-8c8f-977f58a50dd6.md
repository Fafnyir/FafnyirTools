## EllesmereUI/Fafnyir mapping

| Skin component | Portability | Proposed mapping |
|---|---:|---|
| Icon crop | Exact | Set icon texcoords to `0.07, 0.93, 0.07, 0.93`; Fafnyir Tools already supports this. |
| Square shape | Exact | Existing square aura/button geometry. |
| Icon mask | Exact with custom code | Create a `MaskTexture`, assign `Mask`, and attach it to the icon and optionally cooldown swipe. |
| Backdrop fill | Exact with custom layer | Owned background texture behind the icon, selected from the four variants. |
| `Edge` artwork | Close/exact | Register or apply it as an Ellesmere textured border, after calibrating edge size and offsets. |
| `Border` artwork | Exact with custom overlay | Dedicated texture above the icon/cooldown. It should not be conflated with the backdrop’s `Edge`. |
| Cooldown inset | Exact | Anchor the cooldown one logical pixel inside each edge or size it to `buttonSize - 2`. |
| Normal artwork | Exact with custom overlay | Persistent overlay texture. |
| Highlight | Exact on clickable buttons | Use the button’s highlight texture or an owned overlay driven by mouse state. |
| Checked | Exact on action buttons | Use checked texture/state where the underlying button exposes it. |
| Pushed | Exact on action buttons | Use pushed texture/state. |
| Disabled | Mostly exact | Use disabled texture where that state exists; otherwise drive an overlay from usability/desaturation state. |

The current Ellesmere aura style table directly supports dimensions, icon texcoords, textured borders, cooldown direction/edge, text, and dispel overlays. It does not expose generic `Normal`, `Highlight`, `Checked`, `Pushed`, `Disabled`, `Backdrop`, or icon-mask fields. Those require Fafnyir-owned regions around the existing aura button. This matches the current official AuraKit implementation: it owns icon, cooldown, border, dispel, and text carriers, but its public style is substantially narrower than a complete Masque skin. [EllesmereUI AuraKit](https://github.com/EllesmereGaming/EllesmereUI/blob/main/EllesmereUI_AuraKit.lua), [Unit-frame aura styles](https://github.com/EllesmereGaming/EllesmereUI/blob/main/EllesmereUIUnitFrames/EUI_UnitFrames_AuraContainers.lua).

## Important limitation: aura icons versus action buttons

For buffs and debuffs, the visually significant pieces are:

- icon crop and mask;
- selected backdrop;
- normal/border/edge artwork;
- cooldown inset;
- duration and stack text.

Aura icons normally have no meaningful checked, pushed, or disabled state. Highlight is useful only for mouseover feedback. Consequently, Fafnyir Tools can reproduce nearly the entire visible aura appearance while omitting several unused Masque action-button states.

A full action-bar port is also technically possible, but is a separate and more invasive feature. EllesmereUI action bars already manage icon cropping, textured borders, states, glows, cooldowns, and wrappers themselves. Fafnyir Tools would need to integrate with those owned buttons and preserve Ellesmere’s proc glow, usability coloring, range coloring, hotkeys, counts, and empty-slot behavior. [Current action-bar implementation](https://github.com/EllesmereGaming/EllesmereUI/blob/main/EllesmereUIActionBars/EUI_ActionBars_Options.lua). I would not combine that work with the aura-skin port.

   - edge artwork;
   - foreground border;
   - optional mouseover highlight.

8. Treat action-button states as a later module. That implementation can reuse the same assets but needs dedicated handling for highlight, checked, pushed, disabled, proc glow, cooldown, range, and usability states.

9. Validate at multiple icon sizes—16, 24, 30, 32, 36, 48, and 60—because `EdgeSize = 6` at 36×36 may need proportional scaling or fixed source cropping to remain sharp.
